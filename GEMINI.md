# BarberFlow Project Guidelines

## README Update Validation Rule
At the conclusion of each task or code modification in this repository, you must verify if there is a need to update the project's [README.md](file:///Users/felipe/Documents/dev/barberShop/README.md).

To do this:
1. Activate and follow the instructions in the `readme-validator` skill.
2. Ensure any new features, configuration keys, or commands are documented.
3. State in your final message whether the README was updated or not.
